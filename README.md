# CyberStay Hotels - DevSecOps Lab

CyberStay is a fictional hotel reservation platform used to learn
AWS DevSecOps and Cloud Security.

## Architecture

Current AWS architecture:

Client
→ API Gateway
→ Lambda
→ DynamoDB

## AWS Services

- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- AWS IAM
- Amazon CloudWatch

## Current API

POST /reservations

## Project Goal

Build a secure DevSecOps pipeline for CyberStay Hotels.

The project will progressively implement:

- Source Control
- CI/CD
- Infrastructure as Code
- SAST
- SCA
- Secret Scanning
- IaC Security Scanning
- Security Gates
- AWS Deployment
- Monitoring and Detection
